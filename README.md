# فرنود (Farnoud) — ربات فروش VPN + پنل مدیریت

## نصب سریع روی اوبونتو

```bash
sudo bash install.sh
```

سپس `.env` را ویرایش کنید و سرویس‌ها را اجرا کنید.

## اجرای محلی (XAMPP)

1. دیتابیس `farnoudbot` بسازید و `setup_admins.sql` را اجرا کنید
2. `pip install -r requirements.txt`
3. پنل: `python admin_app.py` → http://localhost:5000
4. ربات: `python main.py`

## ورود پنل
- کاربر: `admin`
- رمز: `admin123`

## دستورات ربات
- `/start` — پیام خوش‌آمد (قابل تنظیم از پنل)
- `/admin` — پنل مدیریت دکمه‌ای (فقط ادمین)

## قابلیت‌های فعلی
- تم تیره / روشن
- تغییر رنگ اصلی پنل (شخصی‌سازی)
- تنظیم پیام خوش‌آمدگویی از پنل وب و داخل ربات
